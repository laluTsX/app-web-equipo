# Guia de contribucion
1. Crear una rama feature/<nombre> a partir de develop.
2. Hacer commits pequeños con mensajes claros (feat, fix, docs, test, chore).
3. Abrir un Pull Request hacia develop.
4. Esperar que la integracion continua pase y que el lider tecnico apruebe.
5. Integrar con "Merge" y eliminar la rama de la funcionalidad.
