# App Web Equipo

Aplicacion web desarrollada en equipo. Este repositorio contiene el codigo fuente,
las pruebas automatizadas y la configuracion de integracion continua.

## Flujo de trabajo
- main: codigo estable, siempre listo para produccion.
- develop: integracion de funcionalidades terminadas.
- feature/*: una rama por cada funcionalidad nueva.

Consulta CONTRIBUTING.md para conocer el proceso completo.
